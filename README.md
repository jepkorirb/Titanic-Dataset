# TITANIC DATASET ANALYSIS
The Titanic Dataset is a analysis project that explore passenger informationfrom the Titanic ship disaster of 1912
The project focus on understanding passenger characteristics and indentifing the factors tha influenced the survival
The analysis use microsoft excel to clean organize and analyze the data
1. ## PROJECT OVERVIEW
- To understand the Titanic dataset
- To undestand the no of passengers who survive
- to inverstigate the relationship between age and survival
  # CRISP-MD METHODOLOGY
  ## PHASE 1: BUSINESS UNDERSTANDING
  **objectives**
  To use data analysis to identify patterns and factors associate with survival
  **Business Questions**
  - How many passengers survive
  - How many passenger did not survive
  - Which passenger had the Highest survival rates
  - Which group of passegners were affected most
    **Problem Statement**
    The Titanic disaster resulted in many passengers death this project ws to investigatethe facors associate with the survival
